# همم قرآن V16 — نسخة Full Stack

هذه النسخة تحافظ على واجهة V16 الحالية، وتحوّل التخزين من localStorage إلى PostgreSQL عبر API، مع بقاء localStorage كذاكرة مؤقتة للواجهة فقط. كلمات المرور لا تُرسل ضمن بيانات المستخدمين العامة؛ الخادم يستخدم bcrypt + JWT.

## المكونات
- `frontend/index.html`: الواجهة الأصلية نفسها بعد ربط التخزين بالـ API.
- `src/`: Express API + المصادقة + الصلاحيات.
- `db/schema.sql`: جداول PostgreSQL والمسارات الأربعة.
- `scripts/init-db.js`: إنشاء الجداول والحساب الإداري الافتراضي.

## التشغيل محلياً
1. أنشئ قاعدة PostgreSQL.
2. انسخ `.env.example` إلى `.env` وضع `DATABASE_URL` و `JWT_SECRET`.
3. شغّل `npm install`.
4. شغّل `npm run db:init`.
5. شغّل `npm start`.
6. افتح `http://localhost:10000`.

الحساب الإداري الافتراضي: `admin / admin123` — غيّر كلمة المرور بعد أول دخول.

## النشر المجاني الأسهل
1. أنشئ PostgreSQL مجاني في Neon.
2. ارفع المشروع إلى GitHub.
3. في Render أنشئ Web Service من المستودع.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. أضف `DATABASE_URL` من Neon. `JWT_SECRET` يمكن توليده تلقائياً من Render عند استخدام `render.yaml`.
7. بعد أول Deploy افتح رابط Render؛ الواجهة والـ API يعملان من نفس الرابط.

> ملاحظة: Render Free Web Service ينام بعد 15 دقيقة من عدم النشاط وقد يحتاج قرابة دقيقة عند أول طلب بعد النوم. قاعدة Neon Free لا تنتهي بمدة ثابتة، لكنها لها حدود استخدام مجانية.

## ملاحظة عن البيانات القديمة
إذا كانت لديك بيانات قديمة داخل localStorage من نسخة V16 السابقة، هذه النسخة لا ترفعها تلقائياً إلى قاعدة البيانات حتى لا تُرسل بيانات قديمة بالخطأ. يمكن عمل استيراد لمرة واحدة بعد التأكد من البيانات.
